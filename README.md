CrowdFund — Frontend

A modern, responsive crowdfunding web application that enables users to discover fundraising campaigns, contribute to causes, and manage their fundraising activities.

CrowdFund is designed to provide a seamless crowdfunding experience through an intuitive user interface, interactive dashboards, and secure integration with its backend API.

Features

- User Authentication — Account registration, login, email verification, and password recovery.
- Campaign Discovery — Browse and explore fundraising campaigns.
- Campaign Management — Create campaigns and track their progress.
- Donations — Contribute to campaigns through integrated payment functionality.
- User Dashboard — Manage campaigns, contributions, wallet information, and withdrawal requests.
- Admin Dashboard — Manage users, review campaigns, and configure platform settings.
- Responsive Design — Optimized layouts for desktop, tablet, and mobile devices.
- Real-Time Functionality — Interactive features supported by Socket.IO integration.

Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Node.js and Express.js backend API
- MongoDB database through the backend
- Paystack payment integration
- Socket.IO
- Resend for email-related functionality

 Architecture

CrowdFund uses a separate frontend and backend architecture.

The frontend handles the user interface and client-side interactions, while the backend provides RESTful APIs for authentication, campaign management, donations, payment processing, wallet operations, and administrative functionality.

## Getting Started

To run the frontend locally:

1. Clone this repository.
2. Open the project folder in your code editor.
3. Configure the frontend API base URL to point to your running backend.
4. Open the main HTML file using a local development server, such as the VS Code Live Server extension.
5. Ensure the backend server and required environment variables are configured.

Security

Sensitive operations, authentication, payment verification, and administrative permissions are handled through the backend. Secret API keys and private credentials should never be exposed in frontend code.
